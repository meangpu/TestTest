# GUIDE

การแนะนำระบบต่างๆภายในเมือง รวมถึงวิธีการใช้ชีวิต คำพูด การดำเนินสตอรี่ต่างๆ

## คำพูดในเมืองต่างๆที่เหมาะกับบทบาทและยุคสมัย

#### คำสรรพนาม

คำสรรพนามจะต้องใช้ให้เหมาะกับบริบทบทบาทของตัวละคร \
คนทั่วไป = ข้า - ท่าน , เจ้า ,เอ็ง / กระผม ฉัน - คุณ ,แก \
คนจีน = อั๊ว - ลื้อ \
สามารถใส่พวกหางเสียงได้เช่นกันตามโรลและบทบาทเช่น ขอรับ เจ้าค่ะ ครับ ค่ะ จำเป็นจะต้องเป็นโรลที่ราชนิกุลนิดนึง หากไม่ใช่ก็ให้ลงท้ายด้วยคำว่า หน่ะ แทน โดย<mark style="color:$danger;">**ห้ามใช้คำหยาบหรือ มึง-กู ทุกกรณี**</mark>

#### คำจำเป็นหลักๆในการพูดคุย&#xD;

แม่มด = อาการบัคต่างๆ แคช หลุด\
กระพริบตา ตีตั๋ว = รีเกม\
เข้าโรงนอน = ออกจากเกม\
ออกจากโรงนอน = เข้าเกม\
คิดอะไรในหัว กำลังนึกถึง หลับตา = พับจอ เหม่อ ทำอะไรอย่างอื่นด้านนอก\
จอแก้ว = อัดจอ สตรีม\
ทำมือเป็นรูป = กดปุ่ม\
สเก็ตซ์ภาพ = แคปจอ ถ่ายรูป\
สลักกระเป๋า เลขนำโชค เลขที่ชอบ = เลขไอดี เลขกระเป๋า\
รัฐบาล เจ้าเมือง = แอดมิน\
ติดคุกรัฐบาล = โดนแบน\
จดหมายรัฐบาล = ticket\
วอชิงตันดีซี นิตยาสาร = ดิสคอส\
เล็ง จ้อง = คลิกขวาค้าง

ลำคอ ปาก = ไมค์\
หู = เสียง หูฟัง\
สมอง = สเปคคอม คอม\
สายตา = จอ

สามารถประดิษฐ์คำพูดให้เหมาะกับบทบาทของตัวเองได้

#### ห้ามตัดสินคำพูดคนอื่นโดยการพูดต่อหน้า เพราะอาจจะทำให้ขัดจังหวะบทสนทนาได้&#x20;

เช่น&#x20;คำพูดที่มีการพูดกัน ถ้าใช้คำว่า ครับคืออะไร ที่นี่เขาไม่พูดกันแบบนี้ โดยที่มันพูดได้ตามที่ guide แจ้งไว้ด้านบน\
คนโดนพูดใส่เอามาแจ้งได้ จะถือว่าเป็นการ BK โรลของคนอื่น ยกเว้นแต่พูดผิดจริงสามารถแนะนำตักเตือนกันได้
